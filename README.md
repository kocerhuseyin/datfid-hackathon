# DATFID Hackathon Services

This repository contains the code-only hackathon services for the DATFID demo:

- [datfid-api](datfid-api/README.md): FastAPI backend with job-based fit and forecast endpoints for concurrent demo workloads.
- [datfid-master](datfid-master/README.md): Public proxy layer that forwards SDK-style requests to the backend service.

Local datasets, pitch assets, generated benchmark output, notebooks, caches, and build artifacts are intentionally excluded from this repository.
